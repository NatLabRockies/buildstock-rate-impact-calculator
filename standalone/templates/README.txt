BuildStock Rate Impact Calculator @BRIC_VERSION@ (@BRIC_PLATFORM@)
=================================================================

Start the app
-------------
Double-click "@START_FILE@". The app opens in your web browser.

The first time you start a new version, it sets itself up. This takes a
minute or two and needs about 2.5 GB of free disk space. Later starts are quick.

Closing the browser tab stops the app (after about two minutes), as does the
"Quit app" button in the app's sidebar or closing the terminal window.

@SECURITY_NOTE@

Where things are stored
-----------------------
- The app itself: @INSTALL_DIR@
  Delete this folder to uninstall.
- Logs of recent runs: @LOG_DIR@
  If the app stops unexpectedly, the window shows the end of the latest log;
  please send that file to the BRIC developers.
- Your downloaded data, projects and OpenEI API key: the "Data Directory"
  shown in the app's Setup panel (by default Documents/buildstock_results).
  Upgrading or uninstalling the app does not touch it.
